# 🥗 Diet & Fitness Tracker

An all-in-one fitness and wellness tracker built using **HTML, CSS, and JavaScript**.

This application helps users maintain healthy habits by tracking meals, workouts, hydration, sleep, weight progress, grocery shopping, meal preparation, and menstrual cycles—all from a single responsive web interface.

---

## ✨ Features

### 🍽 Diet Tracking
- Daily meal planner
- Breakfast, lunch, snacks, and dinner
- Multiple meal options
- Calorie tracking
- Healthy meal suggestions

### 💪 Workout Planner
- Daily workout schedule
- Beginner progression
- Weekly exercise plans
- Rest day management

### 💧 Water Tracker
- One-tap hydration tracker
- Daily water goal
- Visual water progress

### 😴 Sleep Tracker
- Sleep schedule
- Bedtime recommendations
- Wake-up tracking
- Sleep history

### 📈 Progress Tracking
- Weight logging
- Daily habit completion
- Progress history

### 🛒 Shopping List
- Grocery checklist
- Weekly shopping planner
- Meal prep reminders

### 🍳 Recipe Library
- Healthy recipes
- Meal preparation instructions
- Cooking guides

### 🌸 Women's Health
- Menstrual cycle tracking
- Period-aware workout adjustments
- Nutrition recommendations

### 🤖 AI Diet Assistant
- Food recommendations
- Calorie estimation
- Meal adjustment suggestions

1. Clone the repository

```bash

```

2. Open the project folder.

3. Open the HTML file in any modern browser.

No installation or dependencies are required.
